# Ariel Dunn — Business Integration & Operations Portfolio

This repository contains Ariel Dunn's no-build portfolio website for GitHub Pages.

## Preview locally

From the repository folder, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Desktop

1. Clone `arieldunn/arieldunn.github.io`.
2. Create a branch named `portfolio-remodel`.
3. Copy the contents of this package into the cloned repository, replacing the old website files.
4. Commit the changes and publish the branch.
5. Create and merge a pull request into `main`.

GitHub Pages should then publish the site at [arieldunn.github.io](https://arieldunn.github.io).
